# PWR Racing Team – Electronics Recruitment

This repository contains my solutions to the recruitment tasks for the PWR Racing Team Electronics department.
The project demonstrates basic STM32 peripheral configuration and embedded firmware integration using STM32 HAL.

## Features

- STM32G473CET3
- 16 MHz external crystal
- 170 MHz system clock
- 5 Hz LED blinking using TIM6 interrupts
- Independent Watchdog
- Classical CAN at 1 Mbit/s
- periodic 2-byte uptime frame with CAN ID 0x738

## Tools

- STM32CubeMX
- STM32CubeIDE
- STM32 HAL
- Git
